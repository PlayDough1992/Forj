# Why Forj

Forj is for communities that want Discord-style communication with a stricter trust and security posture.

This is not a "Discord is bad" argument. Discord is excellent at scale and convenience. Forj is built for a different priority: trust-first community operations.

## The Honest Pitch

If your community needs verified humans, tighter security controls, and transparent infrastructure choices, Forj is a stronger fit.

If your priority is maximum convenience and the largest plug-and-play ecosystem, Discord is still hard to beat.

## What Forj Does Better Today

## 1. Identity Assurance Is Core, Not Optional

Forj uses a KYC-first access model. That means account access is gated by identity verification workflows.

Practical outcome:
- Fewer throwaway accounts
- Higher friction for impersonation and ban evasion
- Better baseline trust in high-stakes communities

Discord is designed for fast onboarding at internet scale. Forj is designed for communities where trust quality matters more than signup speed.

## 2. Security Posture Is Visible and Auditable

Forj ships with security-relevant controls such as:
- JWT auth with token-version invalidation on password changes
- KYC middleware that blocks protected API access until approval
- Signed webhook validation for callback integrity
- Safety filtering pipeline with automated enforcement behavior

Because the code is open source, these controls are inspectable by anyone, not just trusted because a vendor says so.

## 3. Hosted with Focused Governance

Forj is currently operated on an official VPS deployment (not self-hosted).

That gives the project practical advantages right now:
- Faster rollout of security patches in one controlled environment
- Consistent operational policy enforcement
- Clearer incident handling path for maintainers

## 4. Open Source Changes the Trust Model

With Forj, trust can be verified in code.

Benefits:
- Independent review of auth, transport, and moderation paths
- Community review pressure on risky changes
- Faster contribution path for security fixes and hardening

## 5. Feature Set Covers Real Community Operations

Forj already provides core platform functionality:
- Servers, channels, direct messages, and real-time presence
- Role-based permissions and moderation controls
- Invite-based access patterns
- Voice channel support
- Account and profile management flows

In short: this is not just a security demo, it is a working communication platform.

## 6. Roadmap Influence Is Closer to the Community

Forj can move in the direction contributors and operators need, rather than waiting behind a platform-wide priority queue.

If a security gap matters to your users, the path from issue to patch is direct.

## Where Discord Is Still Stronger

Being honest matters:
- Broader ecosystem and integrations
- Bigger network effects
- More mature enterprise-scale polish in many areas
- Lower friction for mainstream onboarding

If those are your top priorities, Discord may be the better choice for your use case.

## Why Teams Still Choose Forj

Teams choose Forj when they need:
- Higher confidence in user identity
- A security-first operating model
- Open-source transparency
- Faster, community-driven security evolution
- A serious hosted alternative focused on trust and control

## Bottom Line

Forj is not "better for everyone."

Forj is better for communities that treat trust and security as product features, not afterthoughts.
